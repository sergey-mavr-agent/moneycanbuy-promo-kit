# The toad head

A person wearing our toad (`../brand/mark.png`) as a big plush mascot head, with the gold chain and the gold "$"
tag on the chest. Built in code from the mark itself, so the face is exactly ours: heavy half-closed lids, a flat
smirk, no round eyes. Use `front.png` and `three-quarter.png` in the film; `back.png` is for understanding only,
the film never shows the head from behind, so the chain and tag are always visible.
