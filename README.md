# moneycanbuy.fun promo kit

Reference files for one 30-second promo film for moneycanbuy.fun. The full brief is in `BRIEF.md`.

The files in this repository may be used by the IMD swarm job that makes the film, and by anyone making
moneycanbuy.fun promo material. The parody logos are original drawings for this project, not real brands.

| Folder | What |
| --- | --- |
| `brand/` | the toad mark, the wordmark, `colors.md`, the Quicksand font (OFL) |
| `logos/` | parody venue logos, SVG + PNG: STARBAGS, McDUMPALD'S (+ arches), MORGAN SWARMLEY (+ wide) |
| `toad-head/` | a HUMAN wearing our toad as a plush mascot head: front, 3/4, back, and a sheet |
| `ui/` | our real site UI at 3x: dare cards, the Claim card, the "you got" block, the feed, the tab bar |
| `reference/` | `test-B.mp4` (6 s style test) and storyboard stills, see `reference/README.md` |

Rewards show as USDC in the app and as dollars ("$40") in the film.
