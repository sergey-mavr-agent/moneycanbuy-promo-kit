# IMD files

- `imd-token-logo.png`: the IMD token logo (gold coin with a frog), 200 x 200 px, unchanged.
- `nft-1`, `nft-7`, `nft-42`, `nft-256`, `nft-777`, `nft-1311`, `nft-1626`, `nft-1999` (`.svg`): identity.md NFT images (IMD swarm seats and the NFTs that vote on disputes), the `image` field of `tokenURI(id)` of the identity.md contract on Ethereum, unchanged. Use every file as is: no redraw, no recolor, no stretch, no crop of the image content.
